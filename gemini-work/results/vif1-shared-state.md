## 3. Lazy Reads of EE RAM / Scratchpad vs. Kick Snapshotting

In [`ps2_memory.cpp`](file:///C:/Users/lovas/Claude/God%20Of%20War/ext/PS2Recomp-kl/ps2xRuntime/src/lib/ps2_memory.cpp), there is a discrepancy between **Chain mode** and **Normal mode** DMA:

1. **Chain Mode DMA (`mode == 1`) &mdash; Snapshotted at Kick Time**:
   - Location: [`ps2_memory.cpp:1351-1568`](file:///C:/Users/lovas/Claude/God%20Of%20War/ext/PS2Recomp-kl/ps2xRuntime/src/lib/ps2_memory.cpp#L1351) (`writeIORegister`).
   - Behavior: Walks tags (`REFE`, `CNT`, `NEXT`, `CALL`, `RET`, `END`) synchronously inside `writeIORegister`, slicing and deep-copying memory buffers into `PendingTransfer::chainBuf`.
   - **Result**: Data is safely snapshotted at kick time.

2. **Normal Mode DMA (`mode == 0`) &mdash; Read Lazily in Worker**:
   - Location: [`ps2_memory.cpp:1347-1350`](file:///C:/Users/lovas/Claude/God%20Of%20War/ext/PS2Recomp-kl/ps2xRuntime/src/lib/ps2_memory.cpp#L1347) (`enqueueTransfer(madr, qwc)`).
   - Behavior: Slices nothing at kick time; stores only `srcAddr` and `qwc` with an empty `chainData`.
   - Read location: [`ps2_memory.cpp:1876, 1895, 1994, 2011`](file:///C:/Users/lovas/Claude/God%20Of%20War/ext/PS2Recomp-kl/ps2xRuntime/src/lib/ps2_memory.cpp#L1876) inside [`processPendingTransfers()`](file:///C:/Users/lovas/Claude/God%20Of%20War/ext/PS2Recomp-kl/ps2xRuntime/src/lib/ps2_memory.cpp#L1821):
     ```cpp
     const uint8_t* src = (srcPhys < PS2_SCRATCHPAD_SIZE)
         ? (m_scratchpad + srcPhys)
         : (m_rdram + (srcPhys & (PS2_RDRAM_SIZE - 1)));
     ```
   - **Hazard**: If the EE thread kicks a normal mode DMA transfer and immediately overwrites or frees that RAM/scratchpad region before the worker thread consumes it, the worker will read corrupted/stale data.

3. **Native Direct Transfers & Shortcuts &mdash; Read Lazily**:
   - Location: [`tryProcessNativeGifImageUploadChain`](file:///C:/Users/lovas/Claude/God%20Of%20War/ext/PS2Recomp-kl/ps2xRuntime/src/lib/ps2_memory.cpp#L2329) and [`tryProcessNativeGifPackedChain`](file:///C:/Users/lovas/Claude/God%20Of%20War/ext/PS2Recomp-kl/ps2xRuntime/src/lib/ps2_memory.cpp#L2410).
   - Behavior: Directly access `m_rdram + madr` and `m_scratchpad + madr` synchronously at call time without snapshotting.
